⭐ 1. كل شروط البيزنس المطلوبة في الكيس
أ) شروط التقييم (AddReview) Service Layer
3 شروط ورا بعض: فحص التقييم 1-5 + فحص التسجيل + منع التكرار.
public string AddReview(ReviewWriteDTO dto, int userId)
{
    // 1. التقييم بين 1 و 5 نجوم
    if (dto.Rating < 1 || dto.Rating > 5)
        return "Rating must be between 1 and 5.";

    // 2. هل مسجل في الكورس؟
    var isEnrolled = _enrollmentRepo.GetAll()
        .Any(e => e.ApplicationUserId == userId && e.CourseId == dto.CourseId);
    if (!isEnrolled)
        return "Must be enrolled in the course.";

    // 3. هل قيّم قبل كده؟ (منع التكرار)
    var alreadyReviewed = _reviewRepo.GetAll()
        .Any(r => r.ApplicationUserId == userId && r.CourseId == dto.CourseId);
    if (alreadyReviewed)
        return "Already reviewed this course.";

    // إضافة وحفظ:
    var rev = new Review { ApplicationUserId = userId, CourseId = dto.CourseId, Rating = dto.Rating, Feedback = dto.Feedback, CreatedAt = DateTime.UtcNow };
    _reviewRepo.Add(rev);
    _reviewRepo.SaveChanges();
    return "Done";
}
ب) تعديل وحذف الريفيو (Ownership) Service Layer 
public bool UpdateReview(int reviewId, int userId, ReviewUpdateDTO dto)
{
    var review = _reviewRepo.GetById(reviewId);
    if (review == null) return false;

    // شرط الملكية: بتاعه هو بس؟
    if (review.ApplicationUserId != userId) return false;

    // شرط: هل لسه مسجل في الكورس؟
    var isEnrolled = _enrollmentRepo.GetAll()
        .Any(e => e.ApplicationUserId == userId && e.CourseId == review.CourseId);
    if (!isEnrolled) return false;

    review.Rating = dto.Rating;
    review.Feedback = dto.Feedback;
    _reviewRepo.Update(review);
    _reviewRepo.SaveChanges();
    return true;
}

🔑 2. سحب الـ UserId في الـ Controller
السطر الذهبي: حط [Authorize] واسحب الـ ID وابعته للسيرفيس:
[Authorize]
[HttpPost]
public IActionResult AddReview(ReviewWriteDTO dto)
{
    int userId = int.Parse(User.FindFirst(ClaimTypes.NameIdentifier)!.Value);
    var res = _reviewService.AddReview(dto, userId);
    if (res != "Done") return BadRequest(res);
    return Ok(res);
}
⚠️ تنبيه: لو نسيت [Authorize] فوق الفانكشن، السطر ده هيضرب NullReferenceException فوراً لأن مفيش يوزر مسجل!
✅ 3. قائمة الفحص قبل ما تنادي الدكتور
  • 📅 التواريخ: وأنت بتعمل تيست، دايماً حط التاريخ في المستقبل (بعد أسبوع: 2026-10-25) عشان متقعش في فخ الـ 24 ساعة.
  • 🔗 الأقواس المعقوفة: اتأكد إن الـ Route مكتوب كدة: "{id}" بين قوسين معقوفين مش "id".
  • 🎯 نوع الـ Method: لو الفانكشن [HttpPut] خليها في بوستمان PUT (لو POST هيديك 405).
  • 🔄 الـ Restart: لو عدلت أي حرف في Program.cs، اقفل السيرفر واعمل Run من جديد.
🛠️ 4. حل أشهر الإيرورات في 5 ثواني
405 Method Not Allowed (Allow: PUT)
السبب: باعت في بوستمان POST والفانكشن نوعها [HttpPut].
الحل: غير القائمة في بوستمان لـ PUT.
400 Bad Request في الـ Cancel
السبب: ميعاد الحجز فات أو باقي أقل من 24 ساعة (البيزنس لوجيك شغال صح!).
الحل: حط تاريخ حجز في المستقبل (بعد أسبوع) وجرب تاني.
404 Not Found في سواجر أو بوستمان
السبب 1: نسيت الأقواس المعقوفة في الكنترولر: [HttpPut("id/...")] $\rightarrow$ صلحها: "{id}".
السبب 2: الـ Id مش موجود في الداتابيز $\rightarrow$ اعمل GET الأول وشوف Id موجود.
401 Unauthorized في بوستمان
السبب: نسخت التوكن بعلامات التنصيص " ".
الحل: انسخ التوكن الصافي اللي بيبدأ بـ eyJ... واختاره Bearer Token.
NullReferenceException في Register
السبب: الـ Constructor معكوس في AccountController أو AccountService!
الحل: اتأكد إنها: _accountService = accountService; و _userManager = userManager;.
NullReferenceException في Add
السبب: نسيت تحط [Authorize] فوق الفانكشن!
الحل: حط [Authorize] فوقها وتيستها بالتوكن في بوستمان.
400 Bad Request: "The ... field is required"
السبب: نسيت علامة الاستفهام في الـ Filter بالكنترولر.
الحل: حط علامة استفهام: string? OrderBy = null.
