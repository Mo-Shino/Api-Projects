# Api-Projects

Collection of ASP.NET Core Web API projects:

- **Enterprise_ECommerce**: ASP.NET Core 8 Web API with Identity, JWT Authentication (HMACSHA256), Personal Shopping Cart Engine, and Product Catalog browsing.
- **InventoryManagementSystem**: Inventory management system with Stock management, CRUD operations, and pagination/filtering.
- **HealthCareSystem**: Health care management system for Doctors, Patients, and medical Issues.
- **HR_Project**: Human Resources management API.
