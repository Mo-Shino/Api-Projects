# Api-Projects

Collection of ASP.NET Core Web API projects:

- **Appointment_Engine**: Personal appointment reservation & scheduling engine with Identity, JWT Authentication (HMACSHA256), Claims-based resource ownership, and 24-hour cancellation business rules.
- **Enterprise_ECommerce**: ASP.NET Core 8 Web API with Identity, JWT Authentication, Personal Shopping Cart Engine, and Product Catalog browsing.
- **InventoryManagementSystem**: Inventory management system with Stock management, CRUD operations, and pagination/filtering.
- **HealthCareSystem**: Health care management system for Doctors, Patients, and medical Issues.
- **HR_Project**: Human Resources management API.
